# The Sports Cafe

Static website for The Sports Cafe — momos, noodles, fries, mojitos, juices and tea, with the match on the big screen.

- `index.html`, `styles.css`, `script.js` — no build step. Open `index.html` or serve the folder.
- `DESIGN.md` — colours, type and components.
- Hosted on GitHub Pages from the `main` branch.
